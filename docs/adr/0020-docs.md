# The guide is a VitePress site whose snippets are type-checked

Docs examples must compile (kickoff brief, lesson 19), as composure-rs's book chapters run as doctests. The guide lives in `docs/guide/`, one chapter per topic in the Rust book's order: getting started, commands, responses, components, handlers and Views, deferring, REST, Webhook Events, middleware, platforms, local development, deploying, testing, troubleshooting. It is built with VitePress, which is itself Vite. Code blocks that show API are ```` ```ts twoslash ```` / ```` ```tsx twoslash ````. `@shikijs/vitepress-twoslash` compiles each against the built packages (`jsxImportSource: "composurejs"`, the same strictness as a bot) with `throws: true`, so a type error fails `pnpm -C docs build`, which CI runs. Readers get the compiler's hover types too, so a page can show `^?` what a handler's arguments are. `// ---cut---` hides setup and `// @filename:` splits a snippet into modules. Twoslash drives the TypeScript 5 compiler API, which TypeScript 7 does not ship, so the docs package pins `typescript@5.9.3` for itself, as `scripts/update-spec.mjs` does for openapi-typescript; the packages stay on TypeScript 7. VitePress 1.6 (stable) runs its own Vite 5 inside the docs package, which does not affect the bots' Vite 8. The ADRs are part of the site under "Decisions", so the reasons are one click from the guide. `.github/workflows/docs.yml` deploys it to GitHub Pages from `main`.
