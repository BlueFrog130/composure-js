# composurejs

Discord bots over HTTP Interactions (no gateway), on any runtime that runs `fetch(Request) => Response`: Cloudflare Workers, Node and Bun. Typed Commands, JSX messages checked against Discord's limits, Inline Handlers, deferred responses and a typed REST client.

```sh
pnpm create composurejs my-bot
```

Guide: [https://bluefrog130.github.io/composure-js/guide/getting-started](https://bluefrog130.github.io/composure-js/guide/getting-started)
