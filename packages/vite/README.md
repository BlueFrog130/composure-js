# @composurejs/vite

The Vite plugin for [composurejs](https://www.npmjs.com/package/composurejs): compiles Inline Handlers, builds for Workers, Node and Bun (`server()`, the Default Server), and runs the Dev Loop in `vite dev`.

```ts
import composure from "@composurejs/vite"
export default { plugins: [composure()] }
```

Guide: [https://bluefrog130.github.io/composure-js/guide/local-dev](https://bluefrog130.github.io/composure-js/guide/local-dev)
