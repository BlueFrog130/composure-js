# @composurejs/cli

`composure sync`: makes Discord's Command Definitions match a [composurejs](https://www.npmjs.com/package/composurejs) App.

```sh
pnpm exec composure sync           # show the plan, ask, apply
pnpm exec composure sync --check   # CI: exit 2 when Discord is out of date
```

Guide: [https://bluefrog130.github.io/composure-js/guide/deploying](https://bluefrog130.github.io/composure-js/guide/deploying)
